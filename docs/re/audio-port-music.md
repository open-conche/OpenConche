# port_music1..3: per-stem clip timelines

Data: `docs/re/audio-port-music.tsv` (66 rows), generated by a workbench script from the project XML (CAD entry 136, key 0xc3b44076) of `CADI_Choc3_Adam  FINAL.CAD`. Units are samples at 44,100 Hz. Rows are sorted by track, then clip start.

Graph walked: `port_musicN` (ArrangementClip) -> `ResourceName` = `New Arrangement N` -> its child MixerChannels `New Track K` (carry the **track volume**; absent = 1) -> `ChildName` TrackPlayer `Track K` -> `SoundList` of clip MixerChannels (carry the **clip volume**; absent = 1) -> `ChildName` LoopBox (carries start/end/loop) -> `ResourceName` SampleResource -> `Url`. `resource_path` is that Url (the symbol-table Key, kept with `\`).

## Columns
- `cue`, `tempo_bpm` (arrangement Tempo), `cue_length_samples` (ArrangementClip TimeLineEndPosition), `cue_loop` (TimeLineLoopEnabled plus TimeLineLoopStartPosition), `master_fade_ms`/`source_fade_ms` (ArrangementClip MasterModeFadeTime/SourceModeFadeTime; note the arrangement object has its own MasterModeFadeTime, 1300 for #1, not recorded here).
- `track_name`: the stem file name (each track holds one stem only). `track_volume`: the `New Track` channel Volume. `clip_index`: position in the track's SoundList (the XML order, NOT time order; e.g. the first block of Bass is index 4).
- `clip_start_samples`/`clip_end_samples`: LoopBox TimeLineStart/EndPosition on the cue timeline. `clip_loop_start`/`clip_loop_end`: ResourceLoopStart/EndPosition inside the stem. `clip_volume`: clip channel Volume. `clip_resource_start/end` and `clip_loop_enabled` are extras (resource start is always 0, loop always enabled; ResourceEnd is the real file length-ish and is not needed).
- `reforged_file`: all 66 rows match a Reforged file by MD5 (the 26 stems are `cadi/audio/C3G<n>_<Stem>.ogg`, same as the basename; nothing is `-`).

## Engine notes
- Render each stem clip at its start sample, playing the stem from resource sample 0 for the clip length; the loop region (0..loop_end) matters only if the clip is longer than the loop (last blocks of #1: 841,622 vs 839,048). Mix = track_volume * clip_volume * stem. Whole cue loops at the cue length (loop start 0), so the tail after the last block is silence (#1: 10,271 samples = 0.23 s).
- Fades: master/source values as in 10.6 (decision, not verified).
